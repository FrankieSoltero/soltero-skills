# acme-ledger

Double-entry ledger service for Acme's billing team.

## Getting started

```
npm install
make dev
```

The server starts on port 3000 from `src/app.js`. Configuration in production is 
loaded via environment variables (see `Docs/SETUP.md` for the full list).

## Testing

```
npm test
```

## More

See `Docs/SETUP.md` for environment setup and `Docs/notes.md` for design patterns.
