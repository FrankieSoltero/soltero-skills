## Sweep 2026-09-01 (window 2026-07-17 → 2026-09-01)

**60 edits: 51 additions, 9 in-place replacements.** Twelve vetted sources across three lanes — six arXiv papers (tool-architecture ablation, adversarial review, programmatic context management, ledger orchestration, real-time failure detection/repair, typed revision contracts, robust stopping, TDD-Agent), three lab blogs (OpenAI Codex-as-a-platform, Anthropic's Claude-5 context-engineering rules, Cursor Router), and one OSS release (Codex CLI 0.152.0).

**New Proven entries (4).** Tool design gains two from the COLM-2026 interface ablation (11,700 trajectories, capability held constant): code-execution/compound tool interfaces (~42% fewer steps, ~56% lower token cost at equal resolve rate, corroborated independently by CodeAct), and the umbrella finding that interface organization moves consistency/exploration/efficiency independent of capability. Context management gains one on quarantining approvals and standing constraints from lossy compaction — the strongest merge of the sweep, joining Codex's five-PR production fix with the ConstraintRot benchmark (violations 0%→30%, up to 59%, restored to 0% by constraint pinning). Verification gains one via upgrade (below).

**Notable supersessions.** The long-standing Watch entry *"Prefer a structured, dedicated agent-computer interface … but this is contested for strong models"* is retired: the controlled study resolves the contest as "atomic tooling buys consistency, not resolve rate, and mostly for weaker models," with a newly-documented efficiency cost for strong actors. *"Bind each verification verdict to a hash of the current tracked source tree…"* rises **Promising → Proven** on a genuinely independent second paper measuring the harm it prevents (stale evidence damaged 34/135 correct starts vs 4/135). *"Explicitly schedule/reset what each agent invocation sees"* rises **Promising → Proven** with a within-paper controlled measurement (context-cap failures 150/500 → 5/500 under curated per-worker slices). *"Choose pass@k … and pass^k"* extends from a deployment-metric choice to a harness-comparison requirement. *"Keep the agent-facing root instructions file short"* picks up Anthropic's >80% system-prompt reduction as a second source family. The red-green TDD entry and the generate-test-repair entry each absorb TDD-Agent ablations — including a stated boundary: dual-track test/code co-evolution beats frozen tests for *agent-generated* suites, but not for committed or oracle tests. The cost-per-solved-task entry now also requires matched output-token caps, and the capability/cost routing entry absorbs Cursor's one-sided 75% uplift gate.

**Merges applied.** Fourteen input tactics collapsed into six entries where sources or paper sections restated one claim: three Codex Guardian tactics → one compaction/authorization entry; three failure-monitor tactics → one monitor entry carrying the disqualifying per-deployment recalibration caveat (AUROC 0.885 → 0.527 on a model swap); three deterministic-check tactics → one verification-layer entry; two located-repair tactics → one; two eviction/event-log tactics → one; two domain-view tactics → one.

**Corrections carried into entries rather than propagated.** The weak actor in 2608.11386 is Qwen3Coder-**30B**, not 3B. That paper's per-run token/step absolutes are a unit-scale transcription error; the percentage deltas hold. Claude Code's context rightsizing lives in the in-session `/doctor` slash command — the terminal `claude doctor` is installation diagnostics only. Scroll-style typed state cannot live in Bash shell variables in Claude Code (working directory persists, shell state does not) — use files or a small DB. The 0.07→0.90 content-detection figure is malformed-JSON only, and its "2 µs" cost covers one sub-check, not the embedding.

**Tier distribution of the 51 additions:** 2 Proven, 30 Promising, 19 Watch. Heaviest growth in Verification & self-repair (17 new entries, largely stopping criteria, verifier calibration, and cheap deterministic layers) and Context management (10). Several Watch entries are logged deliberately as one-paper signals with disclosed weaknesses — NL repo search (precision cost, contradicted by field evidence), the verdict taxonomy (N=100, workshop venue, no significance testing), MARS parallel review (dominated by a cheaper alternative in its own source), and approval-transcript budgets (a bare changelog number bump).
