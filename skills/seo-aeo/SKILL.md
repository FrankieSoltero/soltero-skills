# SEO & AEO

## Overview

Baseline judgment on modern SEO is good — stale-tactic refusals and honest
timelines come free. What this skill adds is DISCIPLINE and CURRENCY: every
recommendation carries its basis label, mechanical checks run before
opinions, AEO guidance comes from the dated reference (not memory), and
measurement is a protocol, not a vibe.

## The Rules

1. **Label every recommendation's basis:** `[stable practice]` or
   `[AEO — as of <reference date>, refresh via sweep]` or `[judgment]`.
   Fast-rotting claims (AI-crawler behavior, answer-engine mechanics,
   algorithm specifics) come from
   [references/practices.md](references/practices.md) — check its freshness
   header; if the topic isn't covered or the date is old, say so and
   recommend a sweep rather than asserting from memory.
2. **Mechanical audit first.** Before any judgment recommendation, run the
   checkable list per [references/audit-checklist.md](references/audit-checklist.md)
   (title/meta lengths, H1/heading structure, schema presence/validity,
   crawler access incl. AI user agents, JS-disabled extractability, internal
   links, canonical) and report each ✓/✗. Cannibalization protocol before
   ANY title/H1 change on an existing site (see practices.md).
3. **No promised rankings or dates, ever.** Ranges with conditions;
   controllable inputs (pages shipped, non-branded impressions) as the
   reportable metrics. Investor-update pressure doesn't change this.
4. **Measurement is the protocol:** baseline 20–40 real buyer prompts across
   the assistants → record citations → fix → re-test the SAME set ~14 days
   later. "Improve citation likelihood," never "get cited."
5. Claim-trace gate inherited from content-marketing: rewritten page copy
   uses the user's real facts or bracketed placeholders — never invented
   check intervals, region counts, or pricing.

## Output contract (audits/optimizations)

```
Mechanical: <check>: ✓|✗ <detail>          (full checklist, first)
Recommendations: <what> — <why> [basis label] — <fix>
Measurement: baseline prompt set + recheck date
Open: <facts needed from the user — bracketed in any copy>
```

## Rationalization Table

| Excuse | Reality |
|--------|---------|
| "I know current AEO practice" | AEO rots quarterly. Reference + date, or recommend a sweep. |
| "The founder needs a confident date" | A missed 'page 1 in 8 weeks' costs more than honesty today. Ranges + controllable inputs. |
| "Mechanical checks are beneath this audit" | They're the auditable half. Run them first, report ✓/✗. |
| "More keywords can't hurt" | Density targets ARE keyword stuffing — a named spam policy. |
