# The 20-second brief

Fill before drafting. Ask batched questions ONLY for blocking unknowns;
default + flag the rest.

- **Audience:** who exactly reads this (role, sophistication)?
- **Goal:** what should change in their head/behavior?
- **CTA (exactly one):** the single next action.
- **Platform(s):** where it ships → pulls the constraint row from
  platform-constraints.md.
- **Voice source:** brand-voice file | approved rules | to-be-proposed.
- **Given facts:** the product/claim facts available for tracing (features,
  pricing, numbers, quotes). Anything outside this list is placeholder or
  cut.

Blocking = the answer changes what gets written (audience, CTA, platform).
Defaultable = tone nuance, length, hashtag count — default and flag.
