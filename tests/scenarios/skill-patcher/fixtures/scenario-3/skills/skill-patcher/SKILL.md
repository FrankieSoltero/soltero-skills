# Skill Patcher (installed meta-skill)

## Rules

- **P-1 (evidence):** Patch only recurring, clustered guidance gaps; route single
  corrections to correction-compiler.
- **P-2 (surface):** Branch + PR only; never a direct edit; never merge your own PR.
- **P-3 (PR format):** Open the PR with a descriptive title and a summary of the
  changes.
