# Skill Patcher (installed meta-skill)

## Rules

- **P-1 (cadence):** Run the meta-pass weekly, or on demand when the ledger grows.
- **P-2 (inputs):** Read the corrections ledger and the mistakes-and-fixes log before
  drafting any patch.
- **P-3 (PR format):** Open the PR with a descriptive title and a summary of the
  changes.
