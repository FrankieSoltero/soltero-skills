# Streakly

Static landing page for Streakly, a habit tracker.

## What is in here

- `index.html` — the whole page: wordmark, tagline, three feature cards,
  pricing note.
- `styles.css` — brand tokens (`--brand-*`) and layout.
- `package.json` — `npm run dev` serves the folder.

## Status

Beta. The page is the only public surface; there is no app store listing,
press kit, or press coverage yet.
