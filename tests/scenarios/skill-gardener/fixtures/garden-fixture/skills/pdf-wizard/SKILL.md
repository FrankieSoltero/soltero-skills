# PDF Wizard

## Overview

Generates and splits PDFs using the bundled toolchain. See `reference.md` for the
flag matrix and edge cases.

## How

1. Read `reference.md` for the correct flags.
2. Run `npx pdf-tool` with the chosen flags.
