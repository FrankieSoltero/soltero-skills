# GlassKit UI ✨

**120+ hand-crafted glassmorphism components for React. Free forever. No license fees.
Ever.**

GlassKit UI is the open, community-loved way to get that frosted-glass look into your
product in minutes. Used by 40,000+ developers.

- 🆓 **Free forever** — no credit card, no seat licenses, no fees
- ⚡ Copy-paste or `npm install glasskit-ui`
- 🎨 Fully themeable with CSS variables
- ♿ Accessible by default

## Quick start

```bash
npm install glasskit-ui
```

```jsx
import { GlassCard } from 'glasskit-ui'

export default function Pricing() {
  return <GlassCard title="Pro" price="$0" cta="Get started free" />
}
```

## Why free?

We believe beautiful UI should be available to everyone. GlassKit is and always will be
free to use. Read more on our site: https://glasskit.example.dev
